# Fotos opcionales para el demo

Si colocas aquí fotos con estos nombres, el instalador las usará en lugar de las ilustraciones
(formatos: `.jpg`, `.jpeg`, `.png` o `.webp`).

**Si el sistema ya está instalado:** doble clic en `actualizar-fotos.bat` (en la carpeta principal)
o `npm run db:photos` dentro de `backend/`. Reemplaza las ilustraciones por las fotos sin borrar
nada y sin apagar el sistema.

| Archivo | Dónde aparece |
|---|---|
| `hero` | Portada de la página de inicio |
| `local` | Sección "Nosotros" y galería |
| `logo` | Logo del sitio |
| `ceviche-clasico`, `ceviche-mixto`, `tiradito-al-aji-amarillo`, `leche-de-tigre` | Carta |
| `causa-de-langostinos`, `choritos-a-la-chalaca` | Carta |
| `arroz-con-mariscos`, `jalea-mixta`, `chicharron-de-pescado`, `sudado-de-pescado` | Carta |
| `chicha-morada-jarra`, `limonada-frozen`, `pisco-sour` | Carta |
| `suspiro-a-la-limena`, `picarones` | Carta |

Ejemplo: `hero.jpg`, `ceviche-clasico.jpg`.
